# Mobile node and proxy group editing

Both apps expose **Config → Proxy groups**. Select Manual or Automatic by latency, choose members, set a default, and reorder members. Automatic groups also expose the probe URL and interval. Empty membership, duplicate names, missing references, and cycles through groups or node detours are rejected. Saving validates the candidate with the native core and stages it; **Apply changes** (iOS) or **Apply saved config** (Android) activates it.

On iOS, **Config → Nodes & sources** opens a source manager. Tap a manual node or subscription to edit it. The trash button or a left swipe opens confirmation on the current page. Cancel preserves the source; Delete removes that source row immediately. The saved configuration stays available until regeneration and Apply. **Saved config nodes** opens the generated nodes, including subscription and imported nodes, for server, port, credential, TLS and common transport editing. Manual nodes have a shortcut to these settings from their source editor. Credentials are concealed in the settings editor until revealed. Duplicate manual names use the saved-config list to avoid ambiguous shortcuts.

Local iOS node settings and group definitions belong to the selected profile, survive app restart, and are reapplied during source generation. Editing a manual share link clears that node’s settings override. Deleting a node removes it from locally saved groups when they retain other members; deleting the last member is rejected with instructions to choose a replacement first. Rename a node referenced by a local group only after removing its old name from those group memberships. Subscription topology changes may also require reviewing saved group memberships before regeneration can succeed. Failed validation keeps the last validated configuration and rule snapshot.

On Android, **Config → Sources** retains direct tap-to-edit and visible edit/delete actions. Saving checks that the original source is still present. Deletion updates the visible page and offers guarded Undo; returning from an editor refreshes the list while preserving its scroll position. Generated node settings remain available in **Config → Nodes**. Proxy group editing uses a separate page with member search, reorder arrows and a visible Save action; leaving unfinished changes prompts before discarding them. Large member lists reveal 100 at a time without losing hidden selections. Editing source links still follows the host regeneration boundary; importing another tunnel package replaces its generated nodes and groups.

Editors reject stale profile/configuration snapshots. Existing unknown configuration fields are preserved. “First selected member” omits the selector’s explicit default so reordering continues to determine the fallback on reopening.

Regression coverage includes iOS source identity preservation, local settings and group persistence through regeneration/restart, native semantic validation failure, stale saves, node deletion and saved group repair, and cycles through node detours/endpoints. Simulator UI tests exercise delete/cancel on the current page and native node/group save/reopen on iPhone and iPad. Android uses JVM graph tests plus native instrumentation for source edit/save, deletion/Undo, member reorder/save/reopen and touch target sizes.
